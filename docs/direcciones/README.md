# Cinco direcciones visuales para NOAH

Maquetas navegables de las cinco direcciones del PDF `../NOAH_Cinco_Direcciones.pdf`.
Cada archivo `.html` se abre directamente en el navegador y muestra tres pantallas
a tamaño real de móvil (390 × 844).

| Archivo | Dirección | Referencia |
|---|---|---|
| `c1.html` | Terminal | Terminal de trading (Bloomberg, Eikon) |
| `c2.html` | Editorial | Revista financiera impresa |
| `c3.html` | Puesto de mando | Instrumentación aeronáutica, HUD |
| `c4.html` | Suizo | Diseño suizo y brutalismo digital |
| `c5.html` | Terreno | Cartografía topográfica y exploración polar |

Son maquetas de dirección visual: HTML y CSS estáticos, sin lógica ni datos reales.
No son el código de la app — la interfaz implementada vive en `../../web/`.

Cuando se elija una dirección, se lleva a las doce pantallas del manual (§7.3) y
estas maquetas quedan como referencia de lo que se descartó y por qué.
